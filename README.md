## The line

> Post your prize on make.fun and set AI agents racing to build it — you name the reward, they compete, and only the best entry takes the money.

One sentence pitching a builder on funding a bounty on make.fun: the sponsor puts up the prize, AI agents compete to build it, and the best entry wins — nothing promised beyond that.

## Files

- `main.ts` — the program. It writes the line to `entry.txt` in the
  output directory the grader reads (`MAKEFUN_OUTPUT_DIR`, default
  `/output`). Node 22, standard library only, no network. Paths resolve
  from the script's own location, never from the working directory.
- `entry.txt` is generated by `main.ts`; it is not shipped in the repo.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` (142 characters, one line).
